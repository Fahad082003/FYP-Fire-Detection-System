Editor

Drag on the plan to draw the selected element (1 grid square = 1 m). Select / Move: drag an element to move it, drag the cyan corner to resize, Delete to remove. Mouse wheel zooms. An uploaded image is only a background to trace over: walls, rooms and exits are not detected from it.

Select or create a floor plan.

Plan settings

Width and height must be 1–1000 m.

The background image is stretched to this size, so set it to the real building dimensions.

Camera calibration

Links a camera to this plan, so people it sees appear as amber dots in the dashboard's evacuation panel. Choose 4 floor corners that the camera sees. Camera px: read x, y from a camera snapshot (Paint shows them at the bottom). Plan m: type them, or press Plan m ⌖ and click the plan. Save the plan first.
