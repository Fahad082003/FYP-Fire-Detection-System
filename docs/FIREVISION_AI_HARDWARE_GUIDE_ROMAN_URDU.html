A · Shuru

1. Ye Guide Kya Hai?

Ye guide batati hai ke asli camera, sensor, sprinkler relay, SMS, Email aur Push ko FireVision AI se kaise jorna hai: kya chahiye, kahan se milega, kaun si setting kahan likhni hai, aur kaise check karein ke kaam kar raha hai.

⚠️ Sab se pehle: FireVision AI ek madadgar system hai, certified fire alarm nahi. Asli sprinkler valve ya building ke fire panel ko khud na jorein. Ye kaam licensed electrician aur fire-safety engineer ka hai. Demo ke liye relay par LED ya buzzer lagayein.

Kaun si cheez kis raaste se judti hai

Hardware Kis raaste se system tak Kahan set hota hai
CCTV / IP camera Camera ka RTSP link → AI service video parhti hai Dashboard → Settings page (Admin)
Camera browser mein dikhana MJPEG ya HLS link (RTSP browser nahi chala sakta) Settings page → "Browser video format"
Smoke / temperature sensor ESP32 (ya gateway) → POST /api/iot/telemetry Sensor database mein (SQL), key .env mein; naqshe par Floor Plan → Edit plan → + Sensor
Sprinkler relay ESP32 → GET /api/iot/sprinklers se haal poochhta hai → relay ON/OFF Sprinkler database mein (SQL)
SMS Twilio (internet) .env
SMS fallback (Optional / Legacy — not part of current scope) USB GSM modem + SIM (internet ke baghair) .env
WhatsApp Twilio WhatsApp sender .env
Telegram (Optional / Legacy — not part of current scope) Telegram bot .env
Email SMTP (jaise Gmail) .env
Browser push VAPID keys (Web Push) aur/ya Firebase Cloud Messaging .env; browser par Enable Alerts ya Notifications page

Channels ka haal dashboard ke Notifications page par dikhta hai (har channel: Configured / Not configured / Disabled + wajah). Wahan se kuch bheja nahi jata; ye sirf settings parh kar batata hai.

Device keys: header X-Device-Key. AI service .env ka Device__ApiKey bhejti hai; sensors aur relay (ESP32) Device__SensorApiKey bhejte hain. Dono keys alag honi chahiyein. Key ghalat ya na ho to API 401 deti hai; doosre role ki key ho to 403. Koi device key sprinkler ON/OFF nahi kar sakti: relay sirf haal parhta hai.

3. Network: API Ko Doosre Devices Ke Liye Kholna

Aam taur par API sirf usi PC par chalti hai (localhost:5291). Camera wali AI service usi PC par ho to kuch nahi karna. Lekin ESP32 sensor/relay doosra device hai, is liye API ko network par kholna hoga.

1. Server ko network par sunne dein (Server wali window mein, start.ps1 ki jagah). SENTINEL_ALLOWED_HOSTS mein is PC ka IP bhi daalein, warna Django doosre device ki request ko 400 de deta hai:

cd C:\Users\m_fahad\Desktop\Project\sentinel-django
$env:SENTINEL_ALLOWED_HOSTS = 'localhost,127.0.0.1,192.168.1.10'
.\.venv\Scripts\python -m uvicorn config.asgi:application --host 0.0.0.0 --port 5291

2. Windows Firewall mein port kholein (PowerShell Run as Administrator, ek dafa):

New-NetFirewallRule -DisplayName "FireVision API 5291" -Direction Inbound -Protocol TCP -LocalPort 5291 -Action Allow

3. Check: doosre device ke browser se http://192.168.1.10:5291/health kholein. {"status":"ok"} aana chahiye.

⚠️ Ye HTTP hai, encryption nahi. Device key network par saaf likhi jati hai. Sirf ghar ya office ke private network par istemaal karein, kabhi internet par khula na chhorein. ℹ️ Django server dashboard bhi isi port (5291) par deta hai, is liye upar wale qadam ke baad doosre PC ke browser se http://192.168.1.10:5291 khul sakta hai. Ye is migration mein test nahi hua; aur HTTP par login password bhi saaf jata hai, is liye sirf private network.

5. Smoke Aur Temperature Sensor Jorna

A. Kya khareedna hai (demo ke liye)

Cheez Kaam Note
ESP32 board WiFi se readings bhejta hai, relay chalata hai Arduino IDE se program hota hai
MQ-2 smoke sensor Dhuwan/gas ⚠️ Is ki reading ppm nahi hoti jab tak calibrate na karein. Demo ke liye raw value ka andaza
DHT22 ya DS18B20 Temperature (°C) Seedha °C deta hai
Asli building ke liye Certified smoke/heat detector + gateway Gateway ko neeche wali API se jorein

B. Sensor ko system mein register karna (SQL, ek dafa)

Sensors page sensors ko sirf dikhata hai; naya sensor banane ka form abhi nahi hai, is liye database mein daalein (API band karke, ya chalti mein bhi chalega). Phir dashboard reload karein:

INSERT INTO SensorNodes (Id, Type, CurrentValue, Threshold, LocationZone, UpdatedAt) VALUES
  (N'smoke-kitchen1', N'Smoke',       0,  300, N'Ground Floor - Kitchen', SYSUTCDATETIME()),
  (N'temp-kitchen1',  N'Temperature', 25, 57,  N'Ground Floor - Kitchen', SYSUTCDATETIME());

Chalane ka tareeqa (file mein save karke):

sqlcmd -S localhost -E -C -d SentinelDb -i sensors.sql
Column Matlab
Id Sensor ka pakka naam; ESP32 yahi bhejega
Type Smoke (ppm) ya Temperature (°C), bilkul isi spelling mein
Threshold Alarm ki had. Smoke 300 ppm, temperature 57 °C (sprinkler bulb ka standard)
LocationZone Camera aur sprinkler wala wahi zone

Darje khud bante hain: had ka 80% = Warning, had paar = Alarm, had ×1.5 (smoke) ya ×1.25 (temp) = Critical.

C. Reading bhejna (API)

POST http://192.168.1.10:5291/api/iot/telemetry
Header: X-Device-Key: <Device__SensorApiKey>
Header: Content-Type: application/json
Body:   {"readings":[{"sensorId":"smoke-kitchen1","value":40},{"sensorId":"temp-kitchen1","value":26}]}

Jawab: {"updated":["smoke-kitchen1","temp-kitchen1"],"errors":[]}

  • Har 2–5 second baad bhejein.
  • Ghalat sensorId par "Sensor ... not found" aata hai.
  • Ye asli data hai, is liye "simulated" mat bhejein (ya false). true sirf test ke liye hai; us par sprinkler khud nahi chalte.

D. ESP32 ka namoona code (Arduino)

⚠️ Misaal hai, hum ne ESP32 par chala kar nahi dekha. API ka hissa (yahi JSON aur header) asli API par test hua hai.

#include <WiFi.h>
#include <HTTPClient.h>

const char* WIFI_NAME = "AapKaWiFi";
const char* WIFI_PASS = "wifi-password";
const char* API = "http://192.168.1.10:5291";   // server PC ka IP
const char* KEY = "yahan-Device__SensorApiKey";  // .env wali sensor key
const int SMOKE_PIN = 34;                        // MQ-2 ka analog pin

void setup() {
  Serial.begin(115200);
  WiFi.begin(WIFI_NAME, WIFI_PASS);
  while (WiFi.status() != WL_CONNECTED) delay(500);
}

void loop() {
  int raw = analogRead(SMOKE_PIN);   // 0..4095, ppm NAHI: calibration chahiye
  float smoke = raw / 10.0;          // demo ka andaza
  HTTPClient http;
  http.begin(String(API) + "/api/iot/telemetry");
  http.addHeader("Content-Type", "application/json");
  http.addHeader("X-Device-Key", KEY);
  String body = "{\"readings\":[{\"sensorId\":\"smoke-kitchen1\",\"value\":" + String(smoke) + "}]}";
  int code = http.POST(body);
  Serial.printf("telemetry %d\n", code);   // 200 = theek, 401 = key ghalat
  http.end();
  delay(3000);
}

E. Check

  1. Dashboard → Sensors page par smoke-kitchen1 ki reading aur "last update" badalne lage (Normal / Warning / Alarm / Critical / Not reporting / Stale).
  2. Sensor ke paas agarbatti (dhuwan) le jayein: Warning → Alarm.
  3. Alarm par Incidents page mein "Sensor" incident aaye, aur Activity Log mein entry.

F. Sensor ko naqshe (Floor Plan) par lagana

  1. Sidebar → Floor Plan → Edit plan.
  2. Toolbar mein + Sensor dabayein, phir naqshe par wahan click karein jahan sensor laga hai.
  3. Side panel mein Sensor list se sensor chunein. Marker ka naam = sensor id (jaise smoke-kitchen1), bilkul wahi jo SQL mein hai.
  4. Plan save karein. Yahan sirf jagah save hoti hai.

Floor Plan par sensor ka icon apni live reading se rang badalta hai: Online = hara, Warning = peela, Stale/Offline = grey, Active alert = laal.

6. Sprinkler Relay Jorna

A. System relay ko kaise batata hai

System relay ko khud signal nahi bhejta. Relay (ESP32) har 1–2 second baad poochhta hai:

GET http://192.168.1.10:5291/api/iot/sprinklers
Header: X-Device-Key: <Device__SensorApiKey>

Jawab:

[{"id":"spr-kitchen1","zone":"Ground Floor - Kitchen","isActive":true,"mode":"Auto", ...}]

isActive: true = relay ON, false = OFF.

✅ Hum ne asli API par test kiya: smoke 350 bheja (had 300), aur spr-kitchen1 khud isActive: true ho gaya.

B. Sprinkler register karna (SQL, ek dafa)

INSERT INTO SmartSprinklers (Id, Zone, IsActive, Mode, UpdatedAt) VALUES
  (N'spr-kitchen1', N'Ground Floor - Kitchen', 0, N'Auto', SYSUTCDATETIME());
  • Mode: Auto = aag par system khud chalaye, Manual = sirf operator.
  • Dashboard par baad mein badal sakte hain.

C. ESP32 relay ka namoona (upar wale code mein add karein)

const int RELAY_PIN = 26;   // demo: relay par LED/buzzer

void checkSprinkler() {
  HTTPClient http;
  http.begin(String(API) + "/api/iot/sprinklers");
  http.addHeader("X-Device-Key", KEY);
  if (http.GET() == 200) {
    String json = http.getString();
    int i = json.indexOf("\"spr-kitchen1\"");
    bool on = i >= 0 && json.indexOf("\"isActive\":true", i) == json.indexOf("\"isActive\"", i);
    digitalWrite(RELAY_PIN, on ? HIGH : LOW);
  }
  http.end();
}
// setup() mein: pinMode(RELAY_PIN, OUTPUT); digitalWrite(RELAY_PIN, LOW);
// loop() mein: checkSprinkler();

⚠️ Misaal hai, ESP32 par test nahi hua. Asli kaam ke liye ArduinoJson library se JSON parse karein.

C · Alert channels

7. SMS Alerts (Twilio)

Kahan se milega

  1. twilio.com par account banayein.
  2. Twilio Console ke dashboard par Account SID aur Auth Token milte hain.
  3. Console se ek phone number lein (ye "From" number hai).
  4. ⚠️ Trial account sirf verified numbers par SMS bhejta hai. Apna number Console mein verify karein.

.env mein likhein

Notifications__Sms__TwilioAccountSid=AC................................
Notifications__Sms__TwilioAuthToken=................................
Notifications__Sms__FromNumber=+1XXXXXXXXXX
Notifications__Sms__Recipients=+923001234567,+923331234567
  • Number hamesha +92 wali shakal mein (E.164). Kai numbers comma se.
  • Server dobara chalayein (.\stop.ps1 phir .\start.ps1): .env sirf start par parhi jati hai.

Kab jata hai

Sirf emergency par: High/Critical incident, insaan danger zone mein, ya header ka laal Emergency dispatch button (chapter 13).

Check: header → Emergency dispatch → dialog mein tasdeeq → phone par SMS. Notifications page → "Recent notification activity" mein sms: Pending ... ya error. Twilio ka "Pending" matlab Twilio ne message le liya; phone tak pohnchne ki tasdeeq nahi.

8. GSM Modem: SMS Ka Fallback (Optional / Legacy)

🟡 Optional / Legacy — Not Part of Current Scope. Ye channel project ki maujooda zaroori scope mein nahi hai aur required setup ka hissa nahi. Code maujood hai aur automated tests mein check hai, lekin isay set karna zaroori nahi; sirf tab karein jab aap ko khaas taur par chahiye. Is ke baghair baqi system poora chalta hai.

⚠️ Asli modem par test nahi hua. Code sirf fake modem wale automated tests se check hua hai.

GSM modem SIM card se seedha SMS bhejta hai, internet nahi chahiye. Ye sirf tab chalta hai jab Twilio SMS fail ho jaye ya Twilio set hi na ho. Twilio ne SMS le liya to modem se dobara nahi jata.

A. Kya chahiye

  • USB GSM modem, jaise SIM800 ya SIM7600 (USB-serial board ya USB dongle).
  • Active SIM jis mein SMS ka balance/package ho, PIN lock band (PIN wali SIM par modem "SIM not ready" deta hai).
  • Modem ka driver (company ki website se, agar Windows khud na pehchane).

B. COM port dhoondna

  1. Modem USB mein lagayein.
  2. Windows → Device Manager → Ports (COM & LPT) kholein.
  3. Modem wali line ka number note karein, jaise COM5. (Modem nikal kar dobara lagayein: jo line ghayab/wapas ho, wahi modem hai.)

C. pyserial install (ek dafa)

cd C:\Users\m_fahad\Desktop\Project
sentinel-django\.venv\Scripts\python -m pip install pyserial

Is ke baghair Notifications page par GSM "Disabled: pyserial is not installed" dikhata hai.

.env mein likhein

Notifications__Gsm__Port=COM5
Notifications__Gsm__BaudRate=115200
Notifications__Gsm__Recipients=+923001234567,+923331234567
  • Port khali = modem band.
  • BaudRate aam taur par 115200; modem ke manual mein alag ho to wo likhein.
  • Recipients khali = Notifications__Sms__Recipients wale numbers. Numbers E.164 (+92...) mein.
  • Ye naam abhi .env.example mein nahi hain; khud .env mein add karein.

D. System modem se kya kehta hai (AT commands)

CommandMatlab
ATModem jawab de raha hai?
AT+CPIN?SIM tayyar (READY)? Warna "SIM not ready"
AT+CREG?Network par registered (home ya roaming)? Warna "not registered"
AT+CMGF=1Text mode
AT+CMGS="+92..."Har number ko SMS (max 160 harf, Ctrl-Z se bheja jata hai)

+CMGS ka jawab = network ne SMS le liya (status Pending), phone tak pohnchne ki tasdeeq nahi.

Check: Twilio settings khali rakh kar Emergency dispatch karein → Notifications page par gsm: ... line. Pehle modem ko kisi serial tool (jaise PuTTY) se AT bhej kar check kar lein, phir us tool ko band karein: ek waqt mein COM port sirf ek program khol sakta hai.

9. WhatsApp Alerts (Twilio)

⚠️ Asli WhatsApp delivery test nahi hui. Twilio ka jawab sirf "message le liya" (Pending) batata hai.

A. Kahan se milega

  1. Twilio Console → Messaging → WhatsApp senders. Ek approved WhatsApp sender (WhatsApp Business number) chahiye; approval Twilio/Meta ke through hota hai aur waqt le sakta hai.
  2. Testing ke liye Twilio ka WhatsApp Sandbox bhi hai: har receiver pehle sandbox number ko us ka join code WhatsApp karta hai. (Sandbox ke qadam Twilio Console mein dekhein.)
  3. Account SID aur Auth Token wahi Twilio account ke (SMS wale bhi ho sakte hain), lekin .env mein alag likhne hain.

B. .env mein likhein

Notifications__WhatsApp__TwilioAccountSid=AC................................
Notifications__WhatsApp__TwilioAuthToken=................................
Notifications__WhatsApp__FromNumber=+14155238886
Notifications__WhatsApp__Recipients=+923001234567,+923331234567
  • Saare numbers E.164 (+923001234567). whatsapp: khud lagaya jata hai, aap na likhein.
  • WhatsApp ke recipients SMS wale nahi lete; yahan alag likhein.
  • Ye naam abhi .env.example mein nahi hain; khud add karein.

C. Zaroori hadein

  • 24 ghante ki window: WhatsApp business number se aam (free-text) message sirf tab jata hai jab receiver ne pichle 24 ghante mein us number ko message kiya ho. Is ke bahar sirf approved templates chalte hain, aur hamara alert template nahi hai. Is liye receivers waqt waqt par sender ko message karte rahein, warna WhatsApp alert ruk sakta hai.
  • Photo nahi jati: Twilio tasveer sirf public URL se uthata hai aur dashboard public nahi. Sirf text jata hai (log mein "photo not attached").

10. Telegram Alerts (Optional / Legacy)

🟡 Optional / Legacy — Not Part of Current Scope. Ye channel project ki maujooda zaroori scope mein nahi hai aur required setup ka hissa nahi. Code maujood hai aur automated tests mein check hai, lekin isay set karna zaroori nahi; sirf tab karein jab aap ko khaas taur par chahiye. Is ke baghair baqi system poora chalta hai.

⚠️ Asli Telegram delivery test nahi hui (sirf fake Telegram server wale tests).

A. Bot banana

  1. Telegram app mein @BotFather dhoondein (blue tick wala) → /newbot bhejein.
  2. Bot ka naam aur username (aakhir mein bot) dein.
  3. BotFather ek token deta hai, jaise 123456789:AA.... Ye password jaisa hai: kisi ko na dein.

B. Chat id lena

  1. Akele ke liye: apne bot ko Telegram mein kholein aur Start dabayein (ya koi bhi message bhejein). Bot pehle message ke baghair aap ko message nahi kar sakta.
  2. Group ke liye: bot ko group mein add karein (bot group ka member hona zaroori hai), phir group mein koi message bhejein.
  3. Browser mein ye kholein (apna token daal kar): https://api.telegram.org/bot<TOKEN>/getUpdates
  4. Jawab mein "chat":{"id": ...} dhoondein. Aam chat ka id musbat number, group ka id minus se shuru hota hai (jaise -1001234567890).

💡 getUpdates khali aaye to bot ko dobara message bhejein aur page refresh karein. Ye link token dikhata hai, is liye screenshot share na karein.

C. .env mein likhein

Notifications__Telegram__BotToken=123456789:AA................................
Notifications__Telegram__ChatIds=123456789,-1001234567890
  • Kai chats comma se.
  • Ye naam abhi .env.example mein nahi hain; khud add karein.

D. Photo

Agar incident wala camera MJPEG format par hai to camera ki tasveer (snapshot) caption ke saath jati hai; warna sirf text. Telegram ka "ok" matlab message chat mein pohnch gaya, is liye yahan status Delivered aata hai.

11. Email Alerts (SMTP, misaal Gmail)

Kahan se milega (Gmail)

  1. Google account mein 2-Step Verification on karein.
  2. myaccount.google.com/apppasswords par ek App Password banayein (16 harf). Asli Gmail password istemaal na karein.

.env mein likhein

Notifications__Email__SmtpHost=smtp.gmail.com
Notifications__Email__SmtpPort=587
Notifications__Email__UseStartTls=true
Notifications__Email__Username=aapka.email@gmail.com
Notifications__Email__Password=<16 harf ka app password>
Notifications__Email__From=aapka.email@gmail.com
